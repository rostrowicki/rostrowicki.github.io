NHibernate Quick Reference Guide

1. Configuration and Session Factory

  • Create Configuration:

    var configuration = new Configuration();
configuration.Configure();

  • Build Session Factory:

    var sessionFactory = configuration.BuildSessionFactory();

2. Mapping Entities

  • XML Mapping:

    <hibernate-mapping xmlns="urn:nhibernate-mapping-2.2">
  <class name="Namespace.EntityClassName, AssemblyName" table="TableName">
    <!-- Mapping properties here -->
  </class>
</hibernate-mapping>

  • Fluent Mapping:

    public class EntityClassNameMap : ClassMapping<EntityClassName>
{
    public EntityClassNameMap()
    {
        Table("TableName");
        // Mapping properties here
    }
}

3. CRUD Operations

  • Save or Update Entity:

    using (var session = sessionFactory.OpenSession())
using (var transaction = session.BeginTransaction())
{
    session.SaveOrUpdate(entity);
    transaction.Commit();
}

  • Get Entity by ID:

    var entity = session.Get<EntityClassName>(id);

  • Update Entity:

    using (var session = sessionFactory.OpenSession())
using (var transaction = session.BeginTransaction())
{
    session.Update(entity);
    transaction.Commit();
}

  • Delete Entity:

    using (var session = sessionFactory.OpenSession())
using (var transaction = session.BeginTransaction())
{
    session.Delete(entity);
    transaction.Commit();
}

4. Querying

  • HQL (Hibernate Query Language):

    var query = session.CreateQuery("from EntityClassName where Property = :value");
query.SetParameter("value", propertyValue);
var results = query.List<EntityClassName>();

  • Criteria API:

    var results = session.CreateCriteria<EntityClassName>()
                    .Add(Restrictions.Eq("Property", propertyValue))
                    .List<EntityClassName>();

  • LINQ:

    var results = session.Query<EntityClassName>()
                    .Where(e => e.Property == propertyValue)
                    .ToList();

5. Transactions

  • Begin Transaction:

    var transaction = session.BeginTransaction();

  • Commit Transaction:

    transaction.Commit();

  • Rollback Transaction:

    transaction.Rollback();

6. Lazy Loading

  • Enable Lazy Loading in Configuration: 
    configuration.SetProperty("proxyfactory.factory_class", "NHibernate.ByteCode.LinFu.ProxyFactoryFactory, NHibernate.ByteCode.LinFu");

7. Fetch Strategies

  • Eager Loading:

    session.Query<EntityClassName>().Fetch(x => x.Property).ToList();

  • Lazy Loading: By default, NHibernate uses lazy loading for associated entities.

This NHibernate quick reference guide should help you get started with NHibernate ORM.
