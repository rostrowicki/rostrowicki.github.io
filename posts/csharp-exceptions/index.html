C# - Exceptions

 2022-12-20  382 words   2 minutes 
Contents

In C#, an exception is an object that represents an error that occurs during the execution of a program. Exceptions are used to signal that an error has occurred and to provide information about the error.

Exceptions in C# are represented by classes that derive from the System.Exception class. When an error occurs in a C# program, an exception object is created and thrown. The exception can then be caught and handled by the program.

Here’s an example of how to throw and catch an exception in C#:

try
{
    // Code that might throw an exception goes here
    int x = 5;
    int y = 0;
    int z = x / y;
}
catch (DivideByZeroException ex)
{
    // This block is executed if a DivideByZeroException is thrown
    Console.WriteLine("Error: Cannot divide by zero.");
}
catch (Exception ex)
{
    // This block is executed if any other type of exception is thrown
    Console.WriteLine("An error occurred: " + ex.Message);
}

In this example, the code in the try block attempts to divide the variable x by the variable y, which is zero. This causes a DivideByZeroException to be thrown. The exception is caught by the first `catch

Custom Exceptions

In C#, you can create your own custom exception classes by deriving from the System.Exception class and adding any additional properties or methods that you need.

Here’s an example of how to create a custom exception class in C#:

public class MyCustomException : Exception
{
    public MyCustomException(string message) : base(message)
    {
    }

    public MyCustomException(string message, Exception innerException) : base(message, innerException)
    {
    }
}

To use this custom exception class, you can throw an instance of it in your code like this:

throw new MyCustomException("An error occurred.");

You can also catch and handle the custom exception in a try/catch block like any other exception:

try
{
    // Code that might throw a MyCustomException goes here
}
catch (MyCustomException ex)
{
    // This block is executed if a MyCustomException is thrown
    Console.WriteLine("An error occurred: " + ex.Message);
}

Creating custom exceptions can be useful when you want to provide more specific information about an error that occurs in your code. It allows you to define custom exception types that are tailored to your particular application and provide more context about the error to users or other developers.
