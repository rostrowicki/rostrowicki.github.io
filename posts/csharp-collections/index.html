General Information

In C#, a collection is a group of objects that can be iterated over and manipulated as a single unit. There are several built-in collection types in C#, as well as many third-party libraries that provide additional collection types.

Here is a list of the built-in collection types in C#:

  • Array: An array is a fixed-size collection of items of a particular type. It provides fast random access to items, but slower insertion and removal of items.

  • List: A List is a dynamically-sized collection of items of a particular type (specified using the type parameter T). It provides fast insertion and removal at the end of the list, but slower insertion and removal at the beginning or middle of the list.

  • LinkedList: A LinkedList is a dynamically-sized collection of items of a particular type (specified using the type parameter T). It provides fast insertion and removal at any point in the list, but slower random access to items.

  • Queue: A Queue is a dynamically-sized collection of items of a particular type (specified using the type parameter T). It stores items in a First In, First Out (FIFO) order and provides fast insertion and removal at the end and front of the queue, but slower iteration over the items in the queue.

  • Stack: A Stack is a dynamically-sized collection of items of a particular type (specified using the type parameter T). It stores items in a Last In, First Out (LIFO) order and provides fast insertion and removal at the top of the stack, but slower iteration over the items in the stack.

  • Dictionary<TKey, TValue>: A Dictionary<TKey, TValue> is a dynamically-sized collection of key-value pairs, where the keys are of type TKey and the values are of type TValue. It provides fast lookup and insertion, but slower iteration over the items in the dictionary.

  • SortedDictionary<TKey, TValue>: A SortedDictionary<TKey, TValue> is a dynamically-sized collection of key-value pairs that is sorted by key, where the keys are of type TKey and the values are of type TValue. It provides fast lookup and insertion, but slower iteration over the items in the dictionary.

  • SortedList<TKey, TValue>: A SortedList<TKey, TValue> is a dynamically-sized collection of key-value pairs that is sorted by key, where the keys are of type TKey and the values are of type TValue. It provides fast insertion and removal at any point in the list, as well as fast lookup and iteration over the items in the list.

These are the built-in collection types in C#. There are also many third-party libraries that provide additional collection types.

Examples

Here are some examples of C# collection types and how they can be used:

List

This is a generic collection that stores a list of items of a particular type (specified using the type parameter T). It provides fast insertion and removal at the end of the list, but slower insertion and removal at the beginning or middle of the list. Here’s an example of how to create and use a List to store a list of integers:

List<int> numbers = new List<int> { 1, 2, 3, 4, 5 };

// Add an item to the end of the list
numbers.Add(6);

// Insert an item at a particular index
numbers.Insert(2, 10);

// Remove an item from the list
numbers.Remove(4);

// Iterate over the items in the list
foreach (int number in numbers)
{
    Console.WriteLine(number);
}

LinkedList

This is a generic collection that stores a linked list of items of a particular type (specified using the type parameter T). It provides fast insertion and removal at any point in the list, but slower random access to items.

Here’s an example of how to create and use a LinkedList to store a linked list of integers:

LinkedList<int> numbers = new LinkedList<int>();

// Add an item to the beginning of the list
numbers.AddFirst(1);
numbers.AddFirst(2);

// Add an item to the end of the list
numbers.AddLast(3);

// Insert an item before a particular node
LinkedListNode<int> node = numbers.First;
numbers.AddBefore(node, 10);

// Insert an item after a particular node
numbers.AddAfter(node, 20);

// Remove an item from the list
numbers.Remove(2);

// Iterate over the items in the list
foreach (int number in numbers)
{
    Console.WriteLine(number);
}

Dictionary<TKey, TValue>

This is a generic collection that stores a set of key-value pairs, where the keys are of type TKey and the values are of type TValue. It provides fast lookup and insertion, but slower iteration over the items in the dictionary. Here’s an example of how to create and use a Dictionary<string, int> to store a mapping from strings to integers:

Dictionary<string, int> ages = new Dictionary<string, int>
{
    { "Alice", 35 },
    { "Bob", 42 },
    { "Charlie", 28 }
};

// Look up a value by key
int aliceAge = ages["Alice"];

// Add a new key-value pair to the dictionary
ages["David"] = 30;

// Iterate over the keys in the dictionary
foreach (string name in ages.Keys)
{
    Console.WriteLine($"{name} is {ages[name]} years old.");
}

Queue

This is a generic collection that stores a queue of items, where items are added to the end of the queue and removed from the front of the queue. It provides fast insertion and removal at the end and front of the queue, but slower iteration over the items in the queue. Here’s an example of how to create and use a Queue to store a queue of integers:

Queue<int> numbers = new Queue<int>();

// Add an item to the end of the queue
numbers.Enqueue(1);
numbers.Enqueue(2);

// Remove an item from the front of the queue
int first = numbers.Dequeue();

// Check the item at the front of the queue without removing it
int peek = numbers.Peek();

// Iterate over the items in the queue
foreach (int number in numbers)
{
    Console.WriteLine(number);
}

Stack

This is a generic collection that stores a stack of items, where items are added to the top of the stack and removed from the top of the stack. It provides fast insertion and removal at the top of the stack, but slower iteration over the items in the stack.

Here’s an example of how to create and use a Stack to store a stack of integers:

Stack<int> numbers = new Stack<int>();

// Add an item to the top of the stack
numbers.Push(1);
numbers.Push(2);

// Remove an item from the top of the stack
int top = numbers.Pop();

// Check the item at the top of the stack without removing it
int peek = numbers.Peek();

// Iterate over the items in the stack
foreach (int number in numbers)
{
    Console.WriteLine(number);
}

The Stack collection is often used when you need to implement a Last In, First Out (LIFO) data structure, such as when you are implementing an undo feature in an application.
