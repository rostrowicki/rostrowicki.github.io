Nhibernate Join Queryover

Author
 2023-07-06  260 words   2 minutes 
Contents

When working with NHibernate and QueryOver, you can join multiple tables using the JoinAlias method. Let’s say you have the following entities: Person, PersonFavorites, PersonCompany, and Company. You want to join them based on their relationships. Here’s an example of how to do that:

  1. Define your entities (similar to the previous example):

    public class Person
{
    public virtual int Id { get; set; }
    public virtual ICollection<PersonFavorites> Favorites { get; set; }
    public virtual ICollection<PersonCompany> Companies { get; set; }
}

public class PersonFavorites
{
    public virtual Person Person { get; set; }
    public virtual Favorite Favorite { get; set; }
}

public class PersonCompany
{
    public virtual Person Person { get; set; }
    public virtual Company Company { get; set; }
}

public class Company
{
    public virtual int Id { get; set; }
    // Other properties...
}

  2. Query using QueryOver:

    Person personAlias = null;
PersonFavorites personFavoriteAlias = null;
PersonCompany personCompanyAlias = null;
Company companyAlias = null;

var query = session.QueryOver<Person>(() => personAlias)
    .JoinAlias(() => personAlias.Favorites, () => personFavoriteAlias)
    .JoinAlias(() => personAlias.Companies, () => personCompanyAlias)
    .JoinAlias(() => personCompanyAlias.Company, () => companyAlias)
    .Where(() => personCompanyAlias.Person.Name == "John Doe")
    .List<Person>();

In this example, we join Person with PersonFavorites, PersonCompany, and finally with Company.
